## Concrete source/reference API

Add internal/secrets/doc.go, reference.go, source.go and matching *_test.go. Keep secrets independent of library, manifest, lock and cli to avoid import cycles. Proposed signatures (use these unless an existing contract discovered during implementation forces an equivalent, documented adjustment):

    type Reference struct {
        Name string
        Default *string // nil = no default; pointer to empty string = explicit empty default
        Start, End int  // byte span [Start,End) in original input
    }
    func ValidName(name string) bool
    func ParseReferences(text string) ([]Reference, error)
    func EnvReference(name string) (string, error)
    type Source interface { ReadCommand(name string) ([]string, error) }
    type EnvSource struct{}
    func (EnvSource) ReadCommand(name string) ([]string, error)

ValidName accepts exactly [A-Za-z_][A-Za-z0-9_]*. EnvReference returns ${NAME}. ParseReferences recognizes ${NAME} and ${NAME:-default}, preserves reference order/spans, supports embedded/multiple references and empty defaults, returns an empty non-nil slice for ordinary text, and errors on malformed ${...} or nested braces. No expansion/evaluation. Errors describe grammar/location without reproducing source text, default text or values. Share this implementation with library/mcp.go validation and RequiredVariables; suspicious must still strip recognized reference spans before inspecting remaining literals. Preserve all current MCP tests/behaviors; add malformed/nested edge cases rather than weakening the schema.

ReadCommand takes a validated variable name (not a shell expression/value) and returns argv for a POSIX sh command that reads it at harness runtime, with no value lookup at generation time. An acceptable template is sh -c with a fixed test for whether NAME is set, followed by printf '%s' of its quoted value. Return nonzero if unset; set-but-empty is successful, consistent with the documented harness semantics. Validate before inserting the name into the fixed template. Return a fresh argv slice. No eval, command execution, os.Getenv, dotenv reads or daypack binary reference in generation. The template carries only the name. Document Source as reference-name -> read-command; future providers can implement it while renderers select the strategy. MCP adapters still emit ${NAME} for the environment source; they need not wrap env-only MCP commands. Optional-default handling remains the harness's job, not ReadCommand's.

## Private storage API and format

Add internal/library/secrets.go and secrets_test.go:

    func WriteSecrets(root, projectRoot string, values map[string]string) error

root is the selected library/config root (callers pass resolved Options.LibraryDir); projectRoot is required and identifies the current project/worktree root. Resolve both to absolute paths. Require an existing library directory, reject a destination equal to or beneath projectRoot using component-aware containment (not string-prefix comparison), and reject symlink components/leaf or any existing non-regular secrets.env. Reuse safePath conventions; tests must canonicalize platform temp-root aliases as existing library fixtures do. Never fall back to cwd, a project .env or a second global location. Validate all names/values and existing file content before any mutation; an empty batch is a no-op and creates no file.

The only payload destination is <root>/secrets.env. Before writing, enforce the same Git hygiene as doctor: tracked or not-ignored secrets.env is an error (including non-Git ignore-rule fallback); extract a shared private hygiene helper if useful rather than calling the whole Doctor and rejecting unrelated invalid artifacts. Missing secrets.env is normal. Existing group/world permission bits must cause the writer to refuse with a safe chmod hint before reading its content; doctor diagnoses that condition as a warning. Successful new/replaced files have mode 0600 independently of umask. Do not silently chmod an unsafe existing file.

Use a deliberately documented shell-sourceable subset, with no new dotenv dependency: blank lines, whole-line # comments, and NAME=value assignments. Support simple unquoted safe literal values and single-quoted literal segments, including the standard apostrophe splice '\'' for an embedded quote. The writer always emits NAME='safely quoted value' lines. Define the unquoted safe alphabet as ASCII letters/digits plus _ . / : @ % + , = -; empty is valid. Reject duplicate names and unsupported/malformed existing syntax, including expansion, command substitution, double quotes and multiline values; report only path/line/variable name, never line text. Reject NUL, CR or LF in incoming values. This conservative subset makes files safe to source and permits exact round-tripping of spaces, quotes, $, backticks, #, equals and backslashes in written values without evaluation.

Parse existing supported assignments without executing/sourcing them. A present name with identical decoded value is idempotent; a different value errors with the name only, leaving the entire file unchanged. Check the whole batch first. Preserve existing bytes/comments/order; append only missing names in sorted order, inserting a separating newline if needed. Repeated identical writes leave bytes and mtime unchanged (unless a genuine write is needed). For mutations, write to a private same-filesystem temp file/directory under root, explicitly chmod 0600, close/sync and atomically publish/replace; clean up on every failure. Never truncate the live file in place. Refuse unsafe destination kinds again before publication. This issue does not require coordinating concurrent import processes; document that limitation rather than claiming lost-update protection.

The importer later allocates <SERVER>_<KEY> names, avoids the reserved Claude names described in its requirement, calls WriteSecrets once per server with the complete batch, and only publishes a sanitized MCP definition after successful storage. A conflict skips that server. This API does not allocate names, inspect harness configs or rewrite MCP definitions itself. Test the handoff with a synthetic caller, not a fake production import command.
